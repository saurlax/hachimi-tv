# Spec Delta

## Purpose

为参考素材及后续创作产物提供独立于应用服务器流量的对象存储能力。用户上传由已认证身份申请临时权限，文件完成后经服务端确认，再进入个人素材清单。

## ADDED Requirements

### Requirement: 直传授权和完成登记
系统 SHALL 为已登录用户签发仅针对服务端分配对象的短期写凭据，长期密钥 MUST 只保存在服务端。系统 SHALL 支持普通与分片上传，并在确认对象存在、大小匹配后登记素材。

#### Scenario: 成功直传
- **WHEN** 登录用户上传文件并完成确认
- **THEN** 文件字节直接传到 COS，素材清单显示已保存对象。

#### Scenario: 未上传即确认
- **WHEN** 用户确认尚不存在的上传对象
- **THEN** 系统返回错误且不将素材标为已保存。

### Requirement: 用户对象访问地址
系统 SHALL 为用户自己的 COS 素材返回可访问地址，未配置 CDN 时 SHALL 返回短期签名的 COS 地址；不得将该地址标为 CDN 加速。平台内置素材 SHALL 使用随代码分发的静态地址，不需要 STS。

#### Scenario: 内置素材独立访问
- **WHEN** 用户未登录或未配置 COS 而浏览内置图库
- **THEN** 内置图片仍通过应用静态地址加载。

### Requirement: 个人云盘和容量配额
系统 SHALL 为每个账号分配独立的 S3 对象前缀，默认逻辑容量为 10,000,000,000 字节。已保存文件与有效上传预留总量 MUST 不超过配额，容量预留 MUST 在数据库事务中完成以防并发超额。系统 SHALL 支持文件夹、上传、下载和删除，不将内置角色计入个人容量。

#### Scenario: 并发上传超额
- **WHEN** 同一账号同时申请的文件大小合计超过剩余容量
- **THEN** 系统只允许可容纳的预留，其余请求返回配额不足且不签发上传凭据。

#### Scenario: 上传大小不符
- **WHEN** 实际对象大小不等于预留大小
- **THEN** 不登记为 ready，普通上传在 COS 策略中限制最大字节数，分片由服务端检查完整的分片大小和序号后完成。

### Requirement: Agent 资产读取边界
系统 SHALL 提供按用户身份与资产 ID 读取已保存文件的服务端函数。未来创作 agent MUST 复用该边界，读取跨账号或未完成资产 MUST 被拒绝；本次不实现 agent 生成执行器。

#### Scenario: Agent 读取其他账号文件
- **WHEN** 使用用户 A 的身份请求用户 B 的资产 ID
- **THEN** 不返回对象内容或访问地址。
