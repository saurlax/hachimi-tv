# Spec Delta

## Purpose

为真实用户提供可持久保存的邮箱密码账号与会话，使上传行为、个人素材和访问权限绑定到同一身份，并在退出后停止授予新的存储操作权限。

## ADDED Requirements

### Requirement: 真实账号与会话
系统 SHALL 支持邮箱密码注册、登录和退出，密码 MUST 使用认证库安全散列保存，会话 MUST 由服务端验证。

#### Scenario: 注册登录后刷新
- **WHEN** 用户注册成功并刷新页面
- **THEN** 页面保留已登录身份且允许访问自己的素材。

#### Scenario: 错误密码
- **WHEN** 用户使用错误密码登录
- **THEN** 系统返回可理解的错误且不建立会话。

### Requirement: 个人素材授权
系统 MUST 拒绝匿名用户申请上传凭据，且不得向其他账号返回个人素材或对象访问地址。

#### Scenario: 匿名上传
- **WHEN** 未登录请求上传会话
- **THEN** 返回未认证错误且不签发 STS。

#### Scenario: 跨账号访问
- **WHEN** 用户访问另一账号的个人素材
- **THEN** 不返回素材内容或下载地址。
